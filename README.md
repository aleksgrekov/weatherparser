# API Парсинга Погоды

[![Python](https://img.shields.io/badge/Python-3.12%2B-blue)](https://www.python.org/) [![FastAPI](https://img.shields.io/badge/FastAPI-Framework-green)](https://fastapi.tiangolo.com/) [![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Database-blue)](https://www.postgresql.org/)

## Описание проекта

API-сервис для парсинга и получения данных о погоде для различных городов. Сервис позволяет добавлять города, получать
данные о погоде, а также управлять записями о погоде. Документация API доступна через Swagger
UI: http://127.0.0.1:8000/docs

## Основной функционал

### 1. Добавление города

- **Метод:** `POST /api/v1/cities/`
- **Описание:** Создает новый город в базе данных.
- **Тело запроса:**
  ```json
  {
    "title": "Название города"
  }
  ```
- **Ответ:**
  ```json
  {
    "id": 1,
    "title": "Название города"
  }
  ```
- **Коды ответа:**
    - `201`: Город успешно добавлен.
    - `409`: Запись уже существует.
    - `422`: Ошибка валидации данных.

### 2. Удаление города

- **Метод:** `DELETE /api/v1/cities/{city_id}`
- **Описание:** Удаляет город и все связанные с ним данные о погоде.
- **Параметры:**
    - `city_id` (integer) – ID города
- **Ответ:**
  ```json
  {
    "message": "Город успешно удален!"
  }
  ```
- **Коды ответа:**
    - `200`: Город успешно удален.
    - `404`: Город не найден.
    - `422`: Ошибка валидации данных.

### 3. Получение данных о погоде

- **Метод:** `GET /api/v1/weather/`
- **Описание:** Возвращает данные о погоде с фильтрацией и пагинацией.
- **Параметры запроса:**
    - `city_title` (string) – Название города (опционально)
    - `start_time` (datetime) – Начало периода (опционально)
    - `end_time` (datetime) – Конец периода (опционально)
    - `page` (integer) – Номер страницы (по умолчанию 1)
    - `limit` (integer) – Количество записей на странице (по умолчанию 10)
- **Ответ:**
  ```json
  {
    "total": 100,
    "page": 1,
    "limit": 10,
    "weather_data": [
      {
        "temperature": 20.5,
        "wind_speed": 5.3,
        "description": "clear sky",
        "timestamp": "2024-03-06T12:00:00Z",
        "city_id": 1,
        "city_title": "Название города"
      }
    ]
  }
  ```
- **Коды ответа:**
    - `200`: Данные успешно получены.
    - `422`: Ошибка валидации данных.

## Технические особенности

- **Язык**: Python 3.12.6
- **Фреймворк**: FastAPI
- **База данных**: PostgreSQL
- **Контейнеризация**: Docker и docker-compose

### Запуск с использованием Docker

1. Настройте переменные окружения, используя файл `.env.template`:
   ```bash
   cp .env.template .env
   ```
   Заполните необходимые значения в файле `.env`. Обратите внимание на переменную `API_KEY="Your api key"`.
   Для получения API-ключа OpenWeather зарегистрируйтесь на сайте
   OpenWeather: https://home.openweathermap.org/users/sign_up.

2. Убедитесь, что значения из файла .env соответствуют параметрам в docker-compose.yml. Замените переменные окружения
   для PostgreSQL:
   environment:
   ```dockerfile
     - POSTGRES_USER=<ваше_значение>
     - POSTGRES_PASSWORD=<ваше_значение>
     - POSTGRES_DB=<ваше_значение>
   healthcheck:
     test: [ "CMD-SHELL", "pg_isready -U <ваше_значение> -d <ваше_значение>" ]
   ```

3. Соберите и запустите контейнеры:
   ```bash
   docker-compose up -d
   ```

4. Убедитесь, что приложение работает: `http://127.0.0.1:8000`
